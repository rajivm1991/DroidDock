DroidDock v0.6.0

Release Notes • October 2026

What's New in v0.6.0

Per-Action Sync Toggles

Choose which actions a folder sync performs — copy, update, and rename — independently. Rename is available when matching by content; a disabled rename falls back to a copy under the new name. Existing saved syncs load unchanged.

Live Sync Scan Progress

The sync preview and the scan before a sync now show a scanning panel with items scanned per side, hashing progress in content mode, and elapsed time.

Sync Result Breakdown

The sync result shows per-type counts for copied, updated, renamed, and deleted items.

A Clearer Sync Dialog

  • Reworded compare-by options with hints, and moved match-by out of advanced
  • Stacked sync direction and options at full width
  • The dialog now scrolls on short windows, with a sticky bordered header and footer
