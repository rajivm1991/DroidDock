DroidDock now opens your phone and your Mac in one window, and a copy goes either way.

Thanks to [PROSKEY](https://github.com/PROSKEY) for the phone-and-Mac window, copy either way, the transfer queue, and the setup and USB debugging screens.

### Highlights

- **Phone and This Mac, side by side.** Drag between the two sides, use Cmd+C then Cmd+V, press Cmd+D, or drop a file from Finder onto the phone side.
- **Transfer queue.** Per-file progress with pause, cancel, and retry. When a name already exists, choose skip, replace, keep both, or ask each time. A replace keeps the original until the new copy finishes.
- **One-click setup.** No adb on your Mac? DroidDock downloads Google's platform-tools, checks them against a pinned checksum, and keeps them in its own folder. No Homebrew, no password. An adb you already have is used first.
- **USB debugging help.** With no phone connected, pick your phone's brand and software version to see the steps.
- **A quick tour.** A one-time walk through the two sides, which you can reopen from Settings.

### Also new

Place marks and back/forward on each side. Filter the open folder or search the folders inside it. Thumbnails for photos and videos on This Mac, with a larger Icons zoom. Rename from the selection bar. New folder on either side. A choice of start folder for the phone. Single-click or double-click to open folders. Ctrl+Tab switches sides, and Cmd+[ and Cmd+] go back and forward. Columns keys work like Finder. A one-time "provided as is" notice on first launch.

### Heads-up

- **Delete now goes up a folder.** It never removes files, and Cmd+Delete no longer deletes on the phone. Use Delete on the file menu or the selection bar.
- **The layout and several shortcuts changed** with the redesign. Cmd+/ lists them.

### Safer copies and sync

- A copy cut short, for example if adb is killed, no longer replaces a good file with a partial one.
- If the phone is unplugged during a sync scan, sync stops instead of planning deletes from a half-finished list.
- Sync ignores DroidDock's in-progress temp files.
- A file name containing "Cancelled" no longer stops the whole queue.
- Symlinked folders open on This Mac, and big folders no longer freeze the window.

### Fixed

Phone search previews in Icons. Rename in Columns and Icons. The `emulated` breadcrumb. Selection after a breadcrumb click. Columns scrolling, and refresh after copy and delete. Escape in the shortcuts help. An empty start folder. Unplugging the phone clears the phone list. "Allow access" for folders macOS blocks. Right-click keeping a multi-selection. A second copy is refused while a conflict question is open.

### Requirements

macOS 10.15 or later, Apple Silicon or Intel. DroidDock isn't signed yet, so if macOS says it's "damaged", run `xattr -cr /Applications/DroidDock.app`.
